# XAUUSD 전용 설정 가이드

이 저장소는 **금만 매매한다**는 전제로 조정되어 있다.
프리셋의 손절 폭 가드, 스프레드 필터, 세션, 필요 자본이 전부 금 기준이다.

```bash
python3 -m crowcode gold                       # 금 기준 수치 + 프리셋별 필요 자본
python3 -m crowcode preflight --paper --balance 3000 --preset intraday
```

---

## 0. 이 저장소의 기준 (엑스네스 MT5)

| | 값 |
|---|---|
| 브로커 | Exness, MT5 |
| 심볼 | `XAUUSD` (Cent 계좌는 `XAUUSDm`) |
| **1 핍** | **$0.10** (= MT5 10포인트) |
| 거래당 리스크 | 2% (상한 3%) |
| 손절 | **20~25핍 = $2.00~$2.50** |
| 목표 | **1:3 → 60~75핍 = $6.00~$7.50** |

핍 기준을 확인하는 법 — **0.01랏에서 금이 $1 움직이면 손익은 $1**이다.
20핍 손절이 $2 리스크라면 20핍 = $2, 즉 **1핍 = $0.10**이다.

```bash
python3 -m crowcode sizing --paper --preset scalp --balance 100
```

```
 1핍 = $0.1   ·   0.01랏에서 1핍 = $0.10   ·   1랏 · $1 움직임 = $100
   손절            금액       랏         리스크       목표        이익
     20핍  $  2.00    0.01   $2.00 ( 2.0%)     60핍     $6.00  ←
     25핍  $  2.50    0.01   $2.50 ( 2.5%)     75핍     $7.50  ←
     40핍  $  4.00    0.00   $0.00 ( 0.0%)    120핍     $0.00  랏 부족
```

### 소액 계좌의 진짜 제약: 0.01랏 아래로 못 간다

$100 계좌에서 2%는 $2다. 손절이 25핍($2.50)이면 필요한 랏은 0.008 —
**최소 랏 0.01 아래라서 원래는 매매가 안 된다.**

그래서 `max_risk_pct`(상한 3%)를 뒀다. 계산된 랏이 최소 랏에 못 미쳐도,
0.01랏의 실제 리스크가 상한 안이면 진입한다. 결과적으로 **실제 리스크는
손절 폭에 따라 2.0~3.0% 사이에서 움직인다.** 40핍($4.00 = 4%)부터는
상한을 넘어 진입하지 않는다.

### 프레임은 측정으로 정했다

20~25핍짜리 **구조적** 손절이 어디서 나오는지 재봤다.

| 프레임 | 구조 손절 중앙값 | 20~25핍 통과율 |
|---|---|---|
| H1 > M15 > M5 | 90핍 ($9.05) | 2% |
| **M15 > M5 > M1** | **24핍 ($2.35)** | **56%** |

그래서 `scalp` 프리셋은 **M15 > M5 > M1** 이다. 상위 프레임에서는
구조가 요구하는 손절이 20~25핍보다 훨씬 넓어서 대부분 기각된다.

구조가 20핍보다 **좁게** 잡히면 20핍까지 넓혀서 쓴다(`sl_mode="clamp"`).
반대로 25핍보다 넓으면 버린다 — 구조 안쪽으로 손절을 밀어 넣으면
그냥 맞으러 가는 자리가 되기 때문이다.

## 1. 단위부터 정리

금은 단위 때문에 사고가 가장 많이 난다.

| | 값 |
|---|---|
| 1 랏 | 100 트로이온스 |
| $1 움직임 (1랏) | **$100** |
| $1 움직임 (0.01랏) | **$1** |
| 호가 단위 | 0.01 |
| MT5 "포인트" 1 | $0.01 |
| **1 핍 (이 저장소 기준)** | **$0.10 = 10포인트** |
| 0.01랏에서 1핍 | **$0.10** |

> 채널이 "SL 2~3핍" 이라고 쓴 것은 **$2~3**, 즉 이 저장소 기준으로는 20~30핍이다.
> (채널은 1핍=$1로 썼다.) 같은 "2핍" 이 브로커에 따라 $2 도 되고 $0.20 도 되니
> 항상 **달러로 환산해서** 확인할 것.

전형적 변동성: **M5 ATR $1.5~4 · H1 $4~10 · D1 $25~40**.
스프레드는 ECN 15~35 포인트($0.15~0.35), 스탠다드 30~60 포인트.

---

## 2. 프리셋 고르기 — 계좌 크기가 결정한다

금은 최소 랏(0.01)에서도 $1 움직임 = $1 이라, **손절 폭이 곧 최소 리스크**다.
손절 $5 짜리 셋업은 최소 랏으로도 $5 를 걸어야 하고, 거래당 1% 로 잡으면 잔고 $500 이 필요하다.

| 프리셋 | 프레임 | 리스크 | 손절 | 목표 | 필요 자본 |
|---|---|---|---|---|---|
| **`scalp` (기본)** | M15 > M5 > M1 | 2% | **20~25핍** | **60~75핍** | **$67 ~ $83** |
| `intraday` | H4 > H1 > M15 | 2% | 25~250핍 | 75~750핍 | $83 ~ $833 |
| `swing` | D1 > H4 > H1 | 2% | 60~600핍 | 180~1800핍 | $200 ~ $2,000 |
| `highrisk` | M15 > M5 > M1 | 6% | 8~40핍 | 24~120핍 | $27 ~ $133 |

`scalp` 이 운용 규칙(2% · 20~25핍 · 1:3)을 그대로 담은 기본 프리셋이다.
`highrisk` 만 채널 원문의 6% 를 기록용으로 남겨 두었다.

"필요 자본" 은 **그 손절 폭의 셋업을 최소 랏으로라도 잡을 수 있는 하한**이다.
왼쪽 값에 못 미치면 시그널이 나와도 계속 `sizing` 으로 기각된다.
오른쪽 값에 못 미치면 손절이 넓은 날은 그냥 건너뛴다.

### 계좌 크기별 권장

| 잔고 | 권장 | 이유 |
|---|---|---|
| ~$500 | `scalp` 또는 관망 | 손절 넓은 셋업은 못 잡는다. 무리하면 리스크%를 올려야 하는데 그게 사고의 시작 |
| $1,000 ~ $3,000 | **`intraday`** | 금 변동성에 가장 잘 맞는다. 하루 1~3번 |
| $3,000 ~ | `intraday` + `swing` 병행 | 계좌를 나눠서 (`crowcode split`) |
| 소액 실험용 | `highrisk` | 아래 경고 참고 |

> **`highrisk` 경고** — 채널이 쓰는 "6% 리스크, 2일 만에 10배" 설정을 그대로 옮긴 것이다.
> 연속 3회 손절이면 18% 가 날아간다. 없어져도 되는 돈으로만, 별도 계좌에서.
> `crowcode` 는 이 설정을 로드할 때 경고를 출력한다.

## 3. 스프레드 — 채널이 가장 많이 지적한 문제

> "M1 은 SL 이 2~3핍이라 스프레드에 죽는다"

이 말을 수치화한 것이 `max_spread_ratio` 다. **스프레드를 절대값이 아니라
손절 폭 대비 비율로 본다.**

| 프리셋 | 허용 비율 | 뜻 |
|---|---|---|
| `swing` | 4% | 손절 $20 이면 스프레드 $0.80 까지 |
| `intraday` | 8% | 손절 $5 이면 $0.40 까지 |
| **`scalp`** | **15%** | **손절 20핍($2.00) 이면 스프레드 $0.30 까지** |
| `highrisk` | 20% | 손절 $1 이면 $0.20 까지 |

### 엑스네스 계좌 종류가 여기서 갈린다

| 계좌 | 금 스프레드(대략) | 20핍 손절에서 |
|---|---|---|
| Standard | $0.20 ~ 0.35 | 아슬아슬. 스프레드 넓어지는 시간대엔 기각된다 |
| Raw Spread / Zero | $0.10 ~ 0.20 + 수수료 | 여유 있다 |

**20핍 손절이면 스프레드가 손절의 10~15%다.** 이건 매 거래에 붙는 고정 비용이라
승률을 그만큼 깎는다. `scalp` 프리셋을 쓸 거라면 Raw Spread 나 Zero 계좌를 권한다.

## 4. 세션

기본값은 **런던 07:00~12:00 GMT + 뉴욕 12:00~17:00 GMT**.
금은 이 두 구간에서 거의 모든 움직임이 나온다. 아시아 세션은 좁은 박스가 잦아 제외했다.

- MQL5 EA: `TimeGMT()` 기준이라 브로커 서버 시간과 무관하다.
- Python: 서버 오프셋을 자동 추정한다. 세션이 밀린 것 같으면 `--server-offset` 을 직접 지정.

## 5. 지표 차단

금은 미국 지표에 즉각 반응한다. 특히 **FOMC · CPI · NFP** 는 발표 직후 $20~40 이 튄다.

```bash
python3 -m crowcode live --news "CPI@2026-09-11 12:30, NFP@2026-10-02 12:30"
```

MQL5 EA 는 `InpNewsTimes` 에 같은 시각을 세미콜론으로 넣는다 (GMT 기준):

```
2026.09.11 12:30;2026.10.02 12:30
```

전체 목록은 `python3 -m crowcode gold` 하단에 있다. **시각은 매달 바뀌므로 직접 갱신해야 한다.**

## 6. 스왑 (보유 비용)

금은 스왑이 대체로 크게 마이너스다. 며칠 보유하는 스윙에서는 이게 성과를 뒤집는다.
브로커의 XAUUSD 스왑(1랏 1박당)을 확인해서 백테스트에 넣을 것:

```bash
python3 -m crowcode backtest --preset swing --swap -12 --spread 0.30 ...
```

수요일 롤오버는 3배로 계산한다(주말 이자 선반영). `scalp`/`intraday` 는 당일 청산이라 영향이 없다.

## 7. 브로커 점검 체크리스트

실전 투입 전에 `preflight` 를 돌리면 아래를 한 번에 확인해 준다.

```bash
python3 -m crowcode preflight --preset intraday        # 단말에 연결해서
```

| 항목 | 봐야 할 것 |
|---|---|
| 심볼 이름 | `XAUUSD` / `XAUUSD.m` / `XAUUSDm` / `GOLD` — 마켓워치의 정확한 이름. `--symbol auto` 로 두면 찾아 준다 |
| 계약 크기 | 1랏 · $1 = $100 이어야 금이다. 다르면 마이크로/센트 계좌 |
| 최소 이격 (`stops level`) | 이 값이 프리셋의 최소 손절 이상이면 **모든 주문이 거부된다** |
| 스프레드 | 위 3장의 비율 안에 들어오는지 |
| 잔고 | 2장의 필요 자본 이상인지 |
| 스왑 | 스윙을 할 거라면 |

## 8. "한 번도 진입을 안 한다" 일 때

이 엔진은 원래 자주 진입하지 않는다 (채널도 "주 3~5 시그널" 이라고 말한다).
그래도 며칠째 아무것도 없으면 로그의 기각 사유 집계를 볼 것.

| 사유 | 뜻과 대처 |
|---|---|
| `session` | 세션 밖. 대부분 정상. 계속 이것뿐이면 서버 시간 오프셋 의심 |
| `sizing` | 잔고가 손절 폭을 감당 못 함 → 상위 프레임 프리셋으로 |
| `spread_ratio` | 스프레드가 손절 대비 과함 → ECN 계좌 또는 상위 프레임 |
| `stops_level` | 브로커 최소 이격 > 손절 폭 → 프리셋 변경 |
| `sl_too_wide` | 구조가 넓게 잡힘. 그 프레임의 셋업이 아님 → 정상 동작 |
| `sweep` / `choch` | 진입 조건 미충족. 가장 흔하고 가장 정상적인 기각 |
| `mtf_conflict` | 중간 프레임이 아직 반대 방향 조정 중 → 정상 |
| `risk_gate` | 당일 한도 도달. 다음 날까지 대기 |

`sizing` 이나 `spread_ratio` 가 대부분이면 **설정이 계좌·브로커와 안 맞는 것**이므로
`preflight` 결과대로 프리셋을 바꿔야 한다.
