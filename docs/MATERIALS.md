# 받은 자료와 검증 결과

사용자가 보낸 학습 자료(베트남어)를 정리하고, 그 안의 주장을 실제
XAUUSD 데이터(M15, 2004-06 ~ 2026-01, 494,235봉)로 잰 기록이다.

**자료를 읽고 그대로 코드에 넣지 않는다.** 재고 나서 살아남는 것만 쓴다.
이 프로젝트가 이미 그 반대로 해서 한 번 실패했다.

## 자료 목록

| 자료 | 내용 | 쓸 수 있나 |
|---|---|---|
| TPO Yugi 1·2 | 마켓 프로파일 (VA·POC·IB·싱글프린트) | **가능** — M15 OHLC 로 계산됨 |
| MALAYSIAN SNR | 2봉 접점 레벨 + 신선도 | **가능** |

## TPO 주장 검증 (`python3 -m tpo.study`)

세션 16,533개, 연결쌍 11,005개.

| 자료의 주장 | 실측 | 판정 |
|---|---|---|
| IB 가 좁으면 다음 세션 돌파 | 96.4% vs 91.1% | **기각** 거의 같다 |
| VA 가 IB 안 → 다음 세션 추세 | 0.729% vs 0.773% | **기각** 오히려 작다 |
| poor high/low 는 뚫린다 | 61.6% vs 58.3% | **약함** 3포인트 |
| 돌파 뒤 앞 POC 로 회귀 | 76.4% vs 대조군 71.9% | **대부분 기저율** |
| 종가가 VA 밖 → 그 VA 무효 | 42.9% vs 59.3% | **채택** 16포인트 |
| 앞 VA 경계에서 다음 세션이 멈춤 | 43.8% (아시아→유럽) | 참고 |

자료의 'IB 1% 이하' 기준은 금에서 **세션의 99%가 해당**돼 비교 자체가
성립하지 않는다. 세션별 사분위로 바꿔서 다시 쟀다.

POC 회귀 76.4% 는 대조군을 붙이기 전까지 대단해 보였다. 앞 세션 레인지의
아무 가격이나 71.9% 가 닿는다. **대조군 없는 비율은 읽지 말 것.**

## SNR 주장 검증 (`snr.study.run`)

레벨 172,066개.

| | 반응률 |
|---|---|
| 1회차 (신선) | 66.4% |
| 2회차 | 65.5% |
| 3회차 이상 | 64.6% |
| **대조군 (아무 봉)** | **62.1%** |
| A형 / V형 | 66.3% / 66.6% — 차이 없음 |

신선도는 실재하지만 **1회차와 3회차의 차이가 1.8포인트**다. 레벨 자체가
대조군보다 4.3포인트 낫다. 있긴 한데 자료가 말하는 크기가 아니다.
A형/V형 구분은 의미가 없었다.

## "승률 70~80%" 주장 검증

자료: *"공급/수요 구역 + H1 반전 확인봉, 역추세 금지 → 승률 70~80%,
RR 1:3, 백테스트로 검증했다"*

실측 (H1 반전봉 + 20봉 추세 방향, 손절 1×ATR, 목표 3R):

```
거래 12,206건   승률 25.8%   기대값 +0.033R
RR 1:3 의 손익분기 승률 = 25.0%
```

**25.8% 다. 70~80% 가 아니다.** 손익분기를 0.8포인트 넘긴, 사실상 본전이다.

RR 1:3 에서 승률 70% 면 기대값이 +1.8R/거래다. 그런 것은 존재하지 않는다.
자료의 다른 주장(EUR 3~5핍 손절에 RR 1:10)도 같은 종류다 — 3~5핍은
스프레드와 잡음 안쪽이라 잴 수 있는 크기가 아니다.

## 정리

받은 자료 중 실측을 통과한 것:

1. **종가가 VA 밖이면 그 VA 는 무효** (16포인트)
2. **레벨의 신선도** — 있지만 작다 (2포인트)
3. **자금관리 원칙** — 거래당 2~3%, RR 1:2 이상. 이건 통계가 아니라
   생존 규칙이라 검증 대상이 아니다. 이미 지키고 있다.

통과하지 못한 것이 훨씬 많다. 그게 정상이다.
